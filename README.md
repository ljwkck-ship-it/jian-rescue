# RESCUE! | JIAN RESCUE CLUB

지안을 위험한 퍼즐 보드에서 안전하게 구하는 가족용 PWA 퍼즐 게임입니다. 숫자 단서를 읽고 지안을 찾으며, 레벨별 위험요소는 열지 않고 표시합니다.

- 첫 행동 뒤에는 긴 미션 설명을 줄여 현재 필요한 다음 행동에 집중하도록 했습니다.
- 행동별 콤보 피드백을 `안전 열기 +1`, `정확한 위험 표시 +2`, `지안 구조 +3`으로 표시합니다.
- 첫 콤보에서 힌트 사용이나 위험 표시 취소 시 콤보가 초기화된다는 규칙을 안내합니다.
- 완료 화면에 안전 탐색·구조·위험 표시·시간 및 콤보 보너스의 점수 구성을 표시합니다.
- 위험을 잘못 열면 관련 단서의 행·열과 해당 위험이 세는 범위를 안내해 재도전을 돕습니다.
- `prefers-reduced-motion` 설정에서는 튜토리얼 펄스와 보상 애니메이션도 중지합니다.
- v26은 자동 테스트 19개 통과와 공개 서버의 정적 자산·서비스 워커 갱신을 확인한 프리징 버전입니다.

### 게임성

- `지안 찾기`에서 **Jian Rescue**로 게임의 목표를 확장했습니다. 지안을 모두 구하는 것뿐 아니라 실제 위험을 정확히 모두 표시해야 성공합니다.
- 전체 여정을 **레벨 1~50**으로 재구성했습니다. 1~19레벨은 위험을 하나씩 익히고, 20레벨부터 쉬운 조합에서 복잡한 조합 순으로 복합 위험이 등장합니다.
- 첫 칸을 고른 뒤 전용 논리 풀이기로 검증해, 지안과 위험을 추측 없이 찾을 수 있는 보드만 생성합니다.
- 위험요소는 웅덩이 → 세찬 바람 → 강아지 똥 → 거미 → 뱀 순서로 바뀌며, 위험 숫자가 바라보는 범위도 종류마다 달라집니다.
- 각 레벨에 제한 시간을 추가했습니다. 시간이 끝나면 실패하며, 최고 기록은 같은 레벨을 완료한 최단 시간으로 저장합니다.

### 튜토리얼과 힌트

- 레벨 1을 정답이 고정된 4×4 체험형 튜토리얼로 구성했습니다. 지정 칸 열기 → 지안 구조 → 위험 표시를 차례로 직접 수행합니다.
- 튜토리얼에서는 시간 제한을 없앴습니다. 새 위험 연습판은 범위를 읽은 뒤 숨은 위험 2곳을 직접 누르는 미니 퍼즐입니다.
- 기존의 안전 칸 자동 공개를 없애고 `단서 → 후보 → 결론`의 3단계 논리 힌트로 교체했습니다. 힌트는 답을 대신 실행하지 않습니다.
- 논리 힌트는 레벨마다 3회 사용할 수 있으며, 시작할 때마다 남은 시간이 5초 → 10초 → 20초 줄어듭니다. 18초 동안 입력이 없으면 다음 힌트 사용 방법을 안내합니다.

### UX와 모바일

- 모바일에서는 핵심 수치와 열기·위험 표시 조작 뒤에 게임판이 바로 나오도록 구성했습니다. 논리 힌트는 타일 바로 아래에 배치했습니다.
- PC는 좌클릭으로 열기·지안 구조, 우클릭으로 위험 표시를 사용합니다. 모바일은 모드를 고르고 탭하거나 길게 눌러 위험을 표시할 수 있습니다.
- 레벨·구조·위험 표시 숫자는 목표에 가까워질수록 글자색이 변합니다.
- 지안을 열면 구조 효과가 나오고, 위험 표시는 현재 위험 아이콘으로 바로 표시됩니다. 새 위험이 처음 등장하면 범위를 보여주는 연습판이 열립니다.
- 남은 시간이 1분·30초·10초가 되면 단계별 시간 경고가 표시됩니다.
- 레벨별 별 3개 평가와 최고 별 기록을 저장합니다. 안전한 진행을 이어가면 콤보와 점수가 오르고, 힌트나 표시 취소 시 콤보가 끊깁니다.

### 디자인과 배포

- 타이틀을 **RESCUE! 🧩**로 바꾸고 Baloo 2 타이틀 폰트와 구조대 테마를 적용했습니다.
- 새 구조대 캐릭터를 로고, 파비콘, 앱 아이콘과 공유 이미지에 통일해서 적용했습니다.
- 저장소와 GitHub Pages 주소를 `jian-finder`에서 `jian-rescue`로 변경했습니다.
- PWA 서비스 워커 캐시는 `jian-rescue-v26`으로 갱신했으며, 버전이 붙은 정적 자산으로 이전 캐시와 충돌하지 않도록 했습니다.

## 게임 방법

1. 첫 칸을 열어 주변 단서를 확인합니다. 첫 칸과 주변 칸은 안전합니다.
2. 큰 숫자는 주변 8칸의 지안 수입니다. 작은 아이콘 숫자의 범위는 현재 위험 규칙에 따라 달라집니다.
3. 지안 칸을 열면 자동으로 구조됩니다.
4. 위험 칸을 열면 실패합니다. 위험 표시는 후보 메모이므로 다시 누르면 지울 수 있습니다.
5. 지안을 모두 구하고 실제 위험을 모두 정확히 표시해야 성공합니다.
6. 남은 시간이 0이 되면 실패합니다. 논리 힌트는 답을 실행하지 않고 풀이 근거를 단계적으로 보여줍니다.

## 실행과 검증

```bash
npm test
npm run serve
```

브라우저에서 `http://localhost:4173/?v=27`을 엽니다. 서비스 워커 캐시가 남아 있으면 `v` 값이 다른 주소로 열거나, 개발자 도구에서 기존 서비스 워커를 해제한 뒤 새로고침합니다.

현재 자동 테스트는 다음을 검증합니다.

- 레벨별 지안·위험 배치 수
- 위험요소의 레벨별 단계 상승
- 레벨 1 튜토리얼 난이도
- 고정 튜토리얼의 시작 칸·지안·위험 위치
- 위험 종류별 단서 범위
- 레벨에 따른 보드·구조 목표·위험 목표 증가
- 첫 클릭과 주변 칸의 안전성
- 레벨 1~50 대표 구간과 복합 위험 보드의 논리 풀이 가능 여부
- 레벨별 제한 시간 증가와 시간 종료 실패
- 위험 표시 수의 목표 초과 방지
- 3단계 논리 힌트가 칸을 대신 열지 않는지
- 위험 열기, 올바른 지안 구조, 위험 후보 표시와 해제의 결과
- 안전 탐색·구조·위험 표시·시간·콤보 점수 합계의 일치 여부

## 프리징 이후 관찰 항목

며칠간 실제로 플레이한 뒤, 반복적으로 확인되는 문제가 있을 때 다음 작업 범위를 정합니다.

- 튜토리얼 첫 칸 클릭률과 레벨 1 완료율
- 레벨 1 완료 후 레벨 2·3 시작률
- 첫 힌트 사용 시점과 첫 위험 오픈 실패율
- 레벨별 첫 실패율·평균 힌트 수·재시도율·중단률
- 단일 위험에서 복합 위험으로 넘어가는 레벨 19 → 20 구간의 이탈률
- 실패가 집중되는 복합 위험 조합
- 평균 최고 콤보, 표시 취소 빈도와 콤보가 재플레이에 미치는 영향

이미지 WebP/AVIF 전환과 GPT 기반 코치는 현재 게임성 검증보다 우선하지 않으므로 보류합니다.

## PWA와 에셋

- `manifest.webmanifest`와 `sw.js`를 통해 설치 및 오프라인 캐시를 제공합니다.
- 앱 아이콘: `assets/icon-192.png`, `assets/icon-512.png`
- 파비콘: `favicon.ico`, `assets/favicon-16.png`, `assets/favicon-32.png`
- 로고: `assets/logo.svg`, `assets/jian-rescue-mascot.png`
- 공유 이미지: `assets/og-image.png`
- 논리 힌트 아이콘: `assets/momo-safety-lantern.png`
- 실사 사진은 저장소에 포함하지 않습니다. 레벨마다 오리지널 일러스트 마스코트 4종(`assets/avatars/`)이 순환합니다.

## 설치

localhost 또는 HTTPS에서 Safari, Chrome, Edge로 바로 플레이하거나 앱으로 설치할 수 있습니다.

- iPhone·iPad: Safari의 **공유 → 홈 화면에 추가**
- Android: Chrome의 **앱 설치** 또는 **홈 화면에 추가**
- Windows·macOS: Chrome/Edge의 주소창 설치 아이콘 또는 브라우저 메뉴의 앱 설치
