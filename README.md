# RESCUE! | JIAN RESCUE CLUB

지안을 위험한 퍼즐 보드에서 안전하게 구하는 가족용 PWA 퍼즐 게임입니다. 숫자 단서를 읽고 지안을 찾으며, 레벨별 위험요소는 열지 않고 표시합니다.

## 2차 공개 테스트

- 배포 버전: `v2.0.0-test-public`
- 배포일: 2026-08-09
- 테스트 기간: 2026-08-09 ~ 2026-08-16
- 테스트 목표: 새 성공 조건, 고정 튜토리얼, 단계형 논리 힌트, 위험별 규칙과 모바일 플레이 감각 확인
- 공개 주소: https://ljwkck-ship-it.github.io/jian-finder/

## 오늘 반영한 내용

- `지안 찾기`를 `지안 구하기` / **Jian Rescue**로 피봇했습니다.
- 초급·중급·고급 선택을 없애고 **레벨 1~99**의 단일 여정으로 통합했습니다.
- 레벨이 오를수록 보드, 구조해야 할 지안 수, 표시해야 할 위험 수가 함께 늘어납니다.
- 위험요소는 레벨에 따라 웅덩이 → 세찬 바람 → 강아지 똥 → 거미 → 뱀으로 바뀌며, 각 위험 숫자가 바라보는 범위도 달라집니다.
- 레벨 1은 4×4 고정 연습판입니다. 지정 칸 열기 → 지안 구조 → 위험 표시를 차례로 직접 체험합니다.
- 지안을 모두 구하고 위험을 정확히 모두 표시하면 성공 효과 후 다음 레벨로 자동 이동합니다.
- 첫 칸을 고른 뒤 전용 논리 풀이기로 검증해, 지안·위험 단서만으로 추측 없이 풀 수 있는 보드만 사용합니다.
- PC는 좌클릭으로 열기·지안 구조, 우클릭으로 위험 표시를 사용합니다. 모바일은 열기·위험 표시 모드를 고르고 탭하며, 길게 누르기로도 바로 위험을 표시할 수 있습니다.
- 논리 힌트는 칸을 대신 열지 않고 `단서 → 후보 → 결론`을 3단계로 설명합니다. 새 힌트를 시작할 때 남은 시간 5초를 사용합니다.
- 각 레벨은 보드 크기와 목표 수에 맞는 제한 시간이 있습니다. 시간이 끝나면 실패하며, 기록은 같은 레벨의 최단 구조 시간으로 저장됩니다.
- 논리 힌트는 모든 레벨에 제공되며, 18초 동안 입력이 없으면 사용 방법을 안내합니다.
- 레벨·구조·위험 표시 숫자는 진행 비율이 높아질수록 색이 바뀝니다.
- 모바일은 핵심 수치와 열기·위험 표시 뒤에 게임판이 바로 나오며, 논리 힌트는 타일 바로 아래에 배치합니다. 상세 미션과 메시지는 게임판 아래에 둡니다.
- 타이틀을 **RESCUE! 🧩**로 바꾸고, 둥근 게임형 타이틀 폰트(Baloo 2)를 적용했습니다.
- 지안 캐릭터를 중학교 2학년 여자아이 느낌의 단정한 구조대 캐릭터로 단순화했습니다. 같은 캐릭터를 로고, 파비콘, 앱 아이콘, OG 이미지에 적용했습니다.
- 서비스 워커 캐시 버전은 `jian-rescue-v21`입니다.

## 게임 방법

1. 첫 칸을 열어 주변 단서를 확인합니다. 첫 칸과 주변 칸은 안전합니다.
2. 큰 숫자는 주변 8칸의 지안 수입니다. 작은 아이콘 숫자의 범위는 현재 위험 규칙에 따라 달라집니다.
3. 지안 칸을 열면 자동으로 구조됩니다.
4. 위험 칸을 열면 실패합니다. 위험 표시는 후보 메모이므로 다시 누르면 지울 수 있습니다.
5. 지안을 모두 구하고 실제 위험을 모두 정확히 표시해야 성공합니다.
6. 남은 시간이 0이 되면 실패합니다. 논리 힌트는 답을 실행하지 않고 풀이 근거를 단계적으로 보여줍니다.

## 레벨 구성

| 구간 | 위험요소 | 위험 숫자가 세는 범위 |
| --- | --- | --- |
| 레벨 1~3 | 웅덩이 | 주변 8칸 |
| 레벨 4~6 | 세찬 바람 | 같은 가로·세로줄 전체 |
| 레벨 7~9 | 강아지 똥 | 주변 8칸과 같은 가로줄 |
| 레벨 10~12 | 거미 | 대각선 줄 전체 |
| 레벨 13~99 | 뱀 | 바로 위·아래·왼쪽·오른쪽 |

## 실행과 검증

```bash
npm test
npm run serve
```

브라우저에서 `http://localhost:4173/?v=21`을 엽니다. 서비스 워커 캐시가 남아 있으면 `v` 값이 다른 주소로 열거나, 개발자 도구에서 기존 서비스 워커를 해제한 뒤 새로고침합니다.

현재 자동 테스트는 다음을 검증합니다.

- 레벨별 지안·위험 배치 수
- 위험요소의 레벨별 단계 상승
- 레벨 1 튜토리얼 난이도
- 고정 튜토리얼의 시작 칸·지안·위험 위치
- 위험 종류별 단서 범위
- 레벨에 따른 보드·구조 목표·위험 목표 증가
- 첫 클릭과 주변 칸의 안전성
- 레벨 1~99 대표 구간에서 생성된 보드의 논리 풀이 가능 여부
- 레벨별 제한 시간 증가와 시간 종료 실패
- 위험 표시 수의 목표 초과 방지
- 3단계 논리 힌트가 칸을 대신 열지 않는지
- 위험 열기, 올바른 지안 구조, 위험 후보 표시와 해제의 결과

## PWA와 에셋

- `manifest.webmanifest`와 `sw.js`를 통해 설치 및 오프라인 캐시를 제공합니다.
- 앱 아이콘: `assets/icon-192.png`, `assets/icon-512.png`
- 파비콘: `favicon.ico`, `assets/favicon-16.png`, `assets/favicon-32.png`
- 로고: `assets/logo.svg`, `assets/jian-rescue-mascot.png`
- 공유 이미지: `assets/og-image.png`
- 논리 힌트 아이콘: `assets/momo-safety-lantern.png`
- 레벨마다 목표 얼굴은 `assets/faces/face-01.png`부터 `face-10.png`까지 순환합니다.

## 설치

localhost 또는 HTTPS에서 Safari, Chrome, Edge로 바로 플레이하거나 앱으로 설치할 수 있습니다.

- iPhone·iPad: Safari의 **공유 → 홈 화면에 추가**
- Android: Chrome의 **앱 설치** 또는 **홈 화면에 추가**
- Windows·macOS: Chrome/Edge의 주소창 설치 아이콘 또는 브라우저 메뉴의 앱 설치
