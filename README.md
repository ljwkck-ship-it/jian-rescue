# Jian Finder

가족용 PWA 퍼즐 게임입니다. 숫자 단서를 보고 숨어 있는 `지안 칸`을 모두 찾고, 폭탄을 피하면 다음 레벨로 넘어갑니다.

- 공개 전환 커밋: `4b0db6e`

현재 빌드는 가족 얼굴 크롭본을 포함한 공개 테스트 버전입니다. 가족이 사용 권한을 확인한 사진을 사용하며, 공개 저장소의 코드·크롭 이미지·raw 자산 URL은 누구나 접근할 수 있다는 점을 전제로 합니다. 가족 외 공유가 필요하지 않은 1주 테스트용 링크로 운영합니다.

## 게임 룰

- 첫 행동은 반드시 `열기`입니다. 첫 칸과 주변 칸은 안전합니다.
- 큰 숫자는 주변 8칸에 숨어 있는 지안이 수입니다.
- 작은 `💣 숫자`는 주변 8칸에 숨어 있는 폭탄 수입니다.
- 지안이가 있는 칸은 `열기`나 `지안 표시`로 찾을 수 있습니다. 올바른 표시는 다시 해제할 수 있습니다.
- 폭탄 칸을 열면 즉시 실패하고 게임이 끝납니다.
- 지안이가 아닌 칸에 `지안 표시`를 하면 폭탄이 터져 실패합니다.
- 이번 판의 지안이를 모두 정확히 표시해야 다음 레벨로 넘어갑니다.

## 실행

```bash
npm test
npm run serve
```

브라우저에서 `http://localhost:4173`을 엽니다. PWA 설치와 서비스 워커는 `localhost` 또는 HTTPS에서 검증하세요.

## PWA 설치 안내

Jian Finder는 설치하지 않아도 Safari, Chrome, Edge에서 일반 웹앱으로 바로 플레이할 수 있습니다. 자주 쓴다면 앱스토어를 거치지 않고 홈 화면이나 응용 프로그램으로 설치할 수 있습니다.

현재 1차 테스트는 공개 GitHub 저장소와 가족 기기에서 진행합니다. 얼굴 크롭본이 포함된 공개 상태를 2026-08-08까지 유지하고, 이후 사진 자산 공개를 계속할지 재검토합니다.

### iPhone·iPad

Safari 사용을 권장합니다.

1. Safari에서 Jian Finder 주소를 엽니다.
2. 화면 아래 또는 위의 **공유** 버튼(사각형과 위쪽 화살표)을 누릅니다.
3. 공유 메뉴를 내려 **홈 화면에 추가**를 선택합니다.
4. 이름이 `Jian Finder`인지 확인하고 **추가**를 누릅니다.
5. 홈 화면에 생긴 Jian Finder 아이콘으로 실행합니다.

iOS에서는 웹페이지 안의 **앱 설치** 버튼보다 Safari의 **공유 → 홈 화면에 추가** 절차가 더 안정적입니다. 메뉴에 항목이 보이지 않으면 **동작 편집**에서 홈 화면에 추가를 활성화하거나 Safari로 다시 열어주세요.

### Android

Chrome 사용을 권장합니다.

1. Chrome에서 Jian Finder 주소를 엽니다.
2. 화면에 표시되는 **앱 설치** 버튼을 누릅니다.
3. 설치 확인 창에서 **설치**를 선택합니다.

앱 안에 설치 버튼이 보이지 않는 경우 Chrome 오른쪽 위 **⋮ 메뉴 → 앱 설치** 또는 **홈 화면에 추가**를 선택합니다. 설치가 끝나면 홈 화면과 앱 목록에서 Jian Finder를 실행할 수 있습니다.

### Windows·macOS

Chrome 또는 Edge에서는 Jian Finder 화면의 **앱 설치** 버튼을 누르면 별도 앱 창으로 설치됩니다. 설치 후 다음 위치에서 실행할 수 있습니다.

- Windows 시작 메뉴 또는 macOS Launchpad/Spotlight에서 `Jian Finder` 검색
- Chrome/Edge 주소창의 설치 아이콘
- Chrome 메뉴의 **저장 및 공유 → 페이지를 앱으로 설치** 또는 Edge 메뉴의 **앱 → 이 사이트를 앱으로 설치**

단, **앱 설치** 버튼은 다음 조건을 만족할 때만 나타날 수 있습니다.

- HTTPS 또는 localhost로 접속
- 브라우저가 PWA 설치를 지원
- 아직 해당 브라우저에 설치하지 않음
- 서비스 워커와 웹 앱 매니페스트가 정상 로드됨

macOS Sonoma 14 이상 Safari에서는 Jian Finder를 연 뒤 메뉴 막대의 **파일 → Dock에 추가**를 사용할 수 있습니다. Safari 설치는 웹페이지 안의 **앱 설치** 버튼이 아니라 Safari 메뉴에서 진행합니다.

## 구현 범위

- 초급 9×9, 레벨 1/16~16/16, 지안 10명~25명
- 중급 16×16, 레벨 1/1, 지안 40명
- 고급 30×16, 레벨 1/1, 지안 99명
- 첫 클릭 안전 배치, 초급·중급 첫 클릭 주변 8칸 보호
- 큐 기반 빈 칸 연쇄 공개
- 지안 칸을 모두 정확히 표시하면 레벨 클리어
- 폭탄 칸을 열거나 잘못 표시하면 실패, 다음 레벨 진행 불가
- PC 좌클릭/우클릭, 모바일 `열기`/`지안 표시` 선택 버튼, 키보드 조작
- 타이머, 게임당 지안 수, 찾은 지안 수, 난이도·레벨별 최고 기록 localStorage 저장
- 매니페스트와 서비스 워커 기반 오프라인 캐시
- 얼굴 사진을 쓰지 않는 파비콘과 OG 이미지
- 레벨이 올라갈 때마다 `assets/faces/face-01.png`부터 `face-10.png`까지 순환 적용
- 사진 로드 실패 시 이모지 대체 표시
- 레벨별 돋보기 힌트 1~2회와 힌트 사용 기록 페널티
- 연속으로 정확한 지안을 표시할 때 정확도 콤보 피드백

## 이번 작업에서 반영한 핵심 수정

- 폭탄도 주변 숫자 단서에 반영해, 폭탄이 완전한 랜덤 벌칙으로만 느껴지지 않도록 했습니다.
- 올바른 `지안 표시`는 실제 토글 동작으로 변경했습니다. 표시한 지안 칸을 다시 해제할 수 있습니다.
- PC 안내를 상단 조작 영역에 노출하고, PC·모바일 모두 `열기`와 `지안 표시`라는 동일한 개념을 사용하도록 문구를 정리했습니다.
- 모바일 첫 화면에서는 게임판을 우선하고, 긴 난이도·룰 패널은 기본 접힘 상태로 변경했습니다.
- 얼굴 사진은 레벨에 필요한 현재 얼굴만 preload하도록 변경했습니다. 서비스 워커 캐시 버전은 `jian-finder-v10`입니다.
- 레벨마다 초급은 돋보기 힌트 2회, 중급·고급은 1회를 제공합니다. 힌트는 안전한 칸을 하나 공개하고, 사용 1회마다 최고 기록에 5초를 더합니다.
- 정확한 지안 표시가 연속되면 `정확한 찾기 +1`, 3회 연속부터 `3연속 성공` 피드백을 보여줍니다. 표시 해제 시 콤보는 초기화됩니다.

## 다음 작업 백로그

아래 항목은 이번 핵심 수정 범위에서는 제외했으며, 다음 작업에서 우선순위를 정해 이어서 진행합니다.

### 게임성

- 지안 수와 폭탄 수를 함께 제공해도 실제 판이 추측 없이 풀리는지 자동 검증하는 생성기와 시뮬레이터를 추가합니다.
- 지안과 폭탄의 역할이 직관적으로 구분되는지 플레이 테스트합니다. 현재는 지안은 찾아야 하고 폭탄은 피해야 하므로 첫 플레이어에게 여전히 인지 부담이 있습니다.
- 초급 레벨별로 지안 수만 증가하는 구조를 넘어, 보드 크기·폭탄 밀도·단서 복잡도도 단계적으로 조정합니다.
- 고급 30×16 보드가 데스크톱에서 가로 스크롤 없이도 충분히 읽히는지 실제 화면 크기별로 검증합니다.
- 타이머와 최고 기록이 운 요소에 의해 왜곡되지 않도록 논리 풀이 가능 판만 기록 경쟁에 포함할지 결정합니다.

### UX·UI

- 게임판보다 히어로·카드·그림자가 강하게 보이는 데스크톱 화면을 더 보드 중심으로 축소합니다.
- 모바일에서 `지안 표시` 모드가 켜져 있다는 사실을 게임판 가까이에서도 지속적으로 인지할 수 있게 보조 상태 표시를 추가합니다.
- `이번 판 지안 0/10`을 `찾음 0 / 전체 10`처럼 더 즉시 이해되는 표현으로 검토합니다.
- 폭탄 공개, 지안 발견, 레벨 성공·실패의 시각·촉각 피드백을 추가하되 `prefers-reduced-motion`을 함께 처리합니다.
- 얼굴 이미지 위의 `지안` 텍스트가 중복 정보인지 테스트하고, 필요하면 상태 배지를 간소화합니다.
- 다크 테마, `theme-color`, `color-scheme`, 난이도별 테마 토큰의 불일치를 정리합니다.

### PWA·성능·개인정보

- Pretendard 외부 CDN 의존을 제거하거나 오프라인 폰트 전략을 정합니다.
- OG 이미지에 배포 도메인 기준 절대 URL을 적용하고 실제 SNS 미리보기를 검증합니다.
- 1주 테스트 종료 후 얼굴 사진을 공개 저장소에 계속 둘지 재검토하고, 필요하면 비식별 캐릭터 빌드로 분리합니다.
- 서비스 워커에 얼굴 사진 전체를 캐시하는 방식 대신 현재 레벨 자산만 필요할 때 캐시할지 검토합니다.
- 실제 Android, iPhone, Windows에서 설치·오프라인 재실행·서비스 워커 갱신을 검증합니다.

### 품질 검증

- DOM 기반 모바일 터치 테스트, PC 우클릭 테스트, 키보드 방향키·포커스 테스트를 추가합니다.
- PWA 설치 가능 조건과 오프라인 재실행을 자동 또는 반자동 체크합니다.
- skip link, 모달 내부 overscroll, 포커스 이동 등 접근성 항목을 별도 점검합니다.

## 사진 자산 정책

- 앱은 `assets/faces/face-01.png`부터 `face-10.png`까지의 중립 파일명 크롭본만 참조합니다.
- 원본 사진 폴더는 앱과 서비스 워커 캐시에 포함하지 않습니다.
- 얼굴 크롭본은 Apple Vision 얼굴 검출 기반 512×512 PNG이며 파일명에 실명·학교·생년월일을 넣지 않습니다.
- 얼굴 크롭본은 EXIF 방향을 반영하고, 돋보기 렌즈 형태의 투명 PNG로 저장했습니다.
- PNG에서 카메라 모델, 촬영일, GPS 등 텍스트 메타데이터 청크를 제거했습니다.
- 공개 테스트를 종료하거나 가족 외 공유 범위가 넓어지면 얼굴 사진을 제거하거나 비식별 캐릭터 이미지로 교체한 뒤 캐시 목록을 재검사하세요.

## 서비스 워커 캐시 초기화

개발 중 변경사항이 반영되지 않으면 브라우저 개발자 도구에서 Application → Service Workers → Unregister를 실행하고, Cache Storage의 `jian-finder-*` 캐시를 삭제하세요.

코드를 바꿔 배포할 때는 `sw.js`의 `CACHE_VERSION` 값을 올리면 오래된 캐시가 활성화 단계에서 정리됩니다.
