게임 방법
  • 큰 숫자는 주변 지안, 작은 아이콘 숫자는 해당 위험의 범위 안에 있는 위험 수예요. 위험마다 범위가 다르니 ‘단서 읽는 법’을 확인하세요.
  • 지안을 모두 구하고 위험을 정확히 모두 표시하면 성공해요.
  • 남은 시간이 0이 되면 실패해요. 레벨 최단은 같은 레벨을 가장 빨리 구조한 기록이에요.
  • 논리 힌트는 3번 사용할 수 있고, 한 번을 시작할 때마다 시간 5초 → 10초 → 20초가 줄어요. 각 힌트는 단서 → 후보 → 결론의 3단계 설명이며, 칸을 대신 열지 않아요.
  • 별은 성공·기준 시간·힌트 없이 완료 조건으로 최대 3개를 받아요. 안전한 행동을 이어가면 콤보와 점수가 올라갑니다.
  • 레벨 20부터는 위험이 둘 이상 등장해요. 표시하려는 위험 아이콘 버튼을 먼저 고르세요.

Jian Rescue 설치 안내

설치하지 않아도 바로 플레이할 수 있습니다. 자주 쓴다면 아래 방법으로 홈 화면이나 앱 목록에 추가하세요.

iPhone·iPad

  1. ↥
    Safari 공유 버튼사각형과 위쪽 화살표 아이콘을 누릅니다.
  2. ＋
    홈 화면에 추가공유 메뉴를 아래로 내려 항목을 선택합니다.
  3. ✓
    추가 후 실행홈 화면의 Jian Rescue 아이콘으로 실행합니다.

Android

  1. ⋮
    Chrome에서 열기앱 설치 버튼이 보이면 바로 누릅니다.
  2. ⬇
    설치 선택확인 창에서 설치를 선택합니다.
  3. ▶
    홈 화면에서 실행홈 화면 또는 앱 목록에서 실행합니다.

Windows·macOS

  1. ⌂
    Chrome 또는 Edge주소창 설치 아이콘이나 앱 설치 버튼을 사용합니다.
  2. ＋
    브라우저 메뉴저장 및 공유 → 페이지를 앱으로 설치를 선택할 수 있습니다.
  3. ⌘
    macOS SafariSonoma 14 이상은 파일 → Dock에 추가를 사용합니다.

설치 버튼은 HTTPS 또는 localhost, 서비스 워커, 매니페스트 조건을 만족하고 아직 설치하지 않은 브라우저에서만 표시될 수 있습니다.
